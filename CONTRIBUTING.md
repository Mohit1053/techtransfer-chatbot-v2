# Contributing to TechTransfer Chatbot

Thank you for considering contributing! This document provides guidelines.

## Code of Conduct

By participating, you agree to maintain a respectful environment.

## Getting Started

1. **Fork** the repository
2. **Clone** your fork:
   ```bash
   git clone https://github.com/YOUR-USERNAME/techtransfer-chatbot.git
   ```
3. **Set up** development environment:
   ```bash
   python -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```

## How to Contribute

### Reporting Bugs

- Check existing issues first
- Include steps to reproduce
- Provide error logs

### Suggesting Features

- Open an issue with `enhancement` label
- Describe the feature and use case

### Code Contributions

1. Create feature branch
2. Make changes
3. Test thoroughly
4. Submit PR

## Commit Guidelines

Follow [Conventional Commits](https://www.conventionalcommits.org/):

```
feat: add new analysis category
fix: resolve PDF parsing error
docs: update installation guide
```

## Pull Request Checklist

- [ ] Code follows style guidelines
- [ ] No secrets or API keys committed
- [ ] Documentation updated
- [ ] Tests added/updated

## Security

⚠️ **NEVER** commit API keys or credentials!
